PRIVACY • locality

This page explains what data the bot uses and how it’s handled. Keep things transparent for everyone in your server.

DATA WE COLLECT

• Basic Discord data such as user IDs, server IDs, role IDs and channel IDs used to operate core features.

• Configuration data you set inside the bot (for example, log channel IDs or moderation settings).

• Limited command usage information for debugging and improving features.

DATA WE DO NOT COLLECT

• We do not log message content unless explicitly required for a feature that you enable (such as moderation logs).

• We do not sell or share your data with third parties for advertising or tracking.

DATA RETENTION

• Configuration and server-related data are stored for as long as the bot is in your server.

• If the bot is removed, stored data may be cleared as part of periodic clean-up.

CONTACT

• If you have questions or want data removed sooner, contact the bot owner via Discord.
